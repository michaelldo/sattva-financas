Backup manual

Prefere não usar o Google? Salve seus dados como arquivo.

Ferramentas

Versão: {{ appVersion }}

Use o backup para levar seus dados para outro celular ou navegador.

  1. Clique em Exportar backup para baixar um arquivo JSON.
  2. Guarde esse arquivo em um lugar seguro, como Google Drive ou computador.
  3. No outro dispositivo, abra o Sattva e clique em Importar backup.
  4. Escolha o arquivo JSON salvo anteriormente.

Ao importar, os dados atuais deste navegador serão substituídos pelo arquivo escolhido.

Dica: conectando o Google Drive, essa cópia é feita automaticamente.
